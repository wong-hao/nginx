# 反向代理网关项目概述

## 一、项目概述

本项目为统一反向代理网关，主要承担域名路由与 TLS 终结核心职责。网关监听标准 443 端口，可根据客户端请求的域名，将 HTTPS 流量精准分发至对应后端业务服务，实现多服务统一 HTTPS 标准端口接入。

## 二、项目背景与建设目的

目前现有两套独立部署的 AI 接口服务，两套服务各自独立运行、端口隔离。由于 HTTPS 标准 443 端口仅支持单一进程占用，无法由多个服务同时监听，导致多域名无法直接通过标准 HTTPS 协议（无端口号）访问。

现有业务服务域名及后端地址信息如下：

|服务名称|域名|后端地址|
|---|---|---|
|Litellm|aigateway\.cdut\.edu\.cn|litellm:4000|
|New\-API|mmaigateway\.cdut\.edu\.cn|new\-api:3000|

为解决上述端口占用冲突问题，本项目搭建独立网关层，统一接管服务器 443 标准端口，通过解析请求的 `server_name` 完成动态路由分发，实现两个域名均支持无端口号的标准 HTTPS 协议访问，统一入口、简化访问方式。
